# history-sync 제거

2026-11-01 사용자 요청으로 장비 간 history-sync를 제품에서 제거했다.
Go relay·SSH 프로토콜·동기화 서비스·설치 옵션·호환 링크는 제공하지 않는다.
구형 `codexm history-sync`나 이전 이름의 호출은 설정·DB를 열기 전에 실패한다.

같은 장비 안에서 계정들이 공용 대화 DB를 이용하는 기능은 그대로다.
장비 사이에는 자동 업로드·다운로드·대화 가져오기를 하지 않는다.
`.home`에도 동기화 도구·서비스·활성 설정을 등록하지 않는다.

기존 `~/.codex-history-sync/v2`와 `~/.codex-sync` 데이터는 복구 자료로 보존한다.
원본 `~/.codex`의 대화·archive·계정 인증을 삭제하거나 예전 데이터로 덮어쓰지 않는다.
과거 문서·Git 이력·마이그레이션 백업은 현재 설치 지침이 아니다.
서비스 종료와 OS 자동 시작 해제는 각 장비에서 확인하며, root 소유 정의의 삭제에는
관리자 인증이 필요할 수 있다. 새 기능으로 다시 켜는 작업은 이 정리에 포함하지 않는다.
