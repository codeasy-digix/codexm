# TUI 대화 모드와 계정 삭제 진입 개선

2026-10-22. 기준 `e252228`. 관리 화면은 유지하고 대화 선택 이후의 경험을
공식 Codex처럼 같은 화면에서 읽고 입력하는 형태로 연결한다.

## 동작

- 작업 목록 클릭 또는 목록 Enter는 해당 대화의 채팅 모드를 연다. 기본 포커스는
  채팅 입력이다. 단순 열람은 등록·실행·계정 변경을 하지 않는다.
- 채팅 모드의 일반 텍스트와 Enter는 선택한 대화에 지시를 보낸다. 빈 입력은
  아무것도 실행하지 않는다. Shift/Alt+Enter는 줄바꿈, ↑↓는 입력 기록이다.
- 검색은 관리 목록과 F8 필터에 남긴다. 목록으로 돌아가기와 관리 탭은 항상
  접근 가능하다. 공식 터미널 열기도 별도 명시적 동작으로 유지한다.
- 대화별 입력 초안과 전송 상태를 분리해 전환 중 다른 대화로 지시가 섞이지
  않게 한다. 늦은 읽기/전송 응답은 원래 대상에만 반영한다.
- 같은 supervisor의 읽기 API로 최근 대화와 진행 중 도구/답변/오류를 갱신한다.
  이전 대화를 추가로 읽을 수 있고 수동 스크롤 위치를 보존한다.
- 처음 전송하는 기존 대화는 공통 등록 API를 거친다. 중지·다른 writer·질문/
  승인 대기는 상태를 알리고 필요한 기존 관리 동작으로 연결한다. 원래 writer
  잠금이나 계정·목표·예산을 강제로 바꾸지 않는다.
- 전송은 기존 durable operation 계층을 사용한다. 처리 중 중복 전송을 막고,
  실패/결과 불명 시 초안을 보존한다. 결과 불명은 확인 전 재전송하지 않는다.
- 계정 목록에서 삭제 동작을 찾을 수 있도록 한다. 실제 삭제는 기존 확인,
  revision 및 관리자/사용 중 계정 보호와 공통 `accounts.remove`를 재사용한다.
  로그인 파일과 과거 대화/로그는 보존한다.

## 검증과 적용

대상 혼선, 미등록 대화 첫 전송, 중지/writer 대기, 중복·불명 전송, 이전 대화
추가 로딩, 스크롤/키보드/마우스와 좁은 화면을 격리 테스트로 확인한다. 실제
tmux/PTY에서 가짜 RPC를 통해 입력·전환·계정 삭제 취소를 확인하고 정리한다.
전체 Go race/vet와 관련 공식 엔진 격리 검사를 통과한 뒤 commit/push하고 로컬
바이너리를 교체한다. 운영 서비스·작업과 인증은 변경하지 않는다. 다른 머신,
릴리스·태그·npm/tap은 이번 범위에 포함하지 않는다.
