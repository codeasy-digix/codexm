# TUI 관리 UX 검증

2026-10-22, 현재 Mac의 최신 제품 소스 `4edf56a`에서 별도 worktree로 작업했다.
기준과 범위는 [구현 계획](tui-gui-parity-plan.md), 사용법은 [README](../README.md#화면과-명령)다.

## 실행한 검사

```sh
go test -race ./...
go vet ./...
CODEXM_NATIVE_TEST=1 CODEXM_BINARY=/absolute/private/validation/codexm \
  go test -race ./internal/supervisor \
  -run 'TestOfficialNativeWorkerLifecycleAndWriterLock|TestOfficialCurrentChatRegistrationAndPausedAccountChangePreserveGoal' \
  -count=1 -v
```

모두 통과했다. 공식 엔진 검사는 읽기 전용 임시 작업·별도 계정 저장소·별도 DB를
사용했다. 실행 중인 다른 writer는 취득하지 않았으며 목표 상태·예산·누적 사용량을
보존했다. 모델에 질문하거나 실제 한도 소진을 유도하지 않았다.

TUI 회귀 검사는 다음을 포함한다.

- 입력 기록·한글 붙여넣기·여러 줄·초안과 선택 대상 보존.
- 설정 충돌과 늦은 조회/로그인 응답, 취소된 로그인 되살림 방지.
- 선택한 대화의 원래 계정과 실행 ID를 포함한 계정 변경. 빈 실행 ID도 명시한다.
- 지원하지 않는/비공개 질문에 Ctrl+S로 잘못 답하지 않음. 지원되는 질문의 답변은 전송.
- 네트워크 결과 불명 뒤 같은 지시/새 작업을 다른 ID로 다시 제출하지 않음.
- 분할 화면과 실제 줄바꿈 너비를 일치시켜 본문 마지막 줄까지 스크롤.
- 전체 로그를 본 뒤 미등록 대화의 로그를 열어도 다른 작업의 기록을 표시하지 않음.
- 계정 선택 중 마우스 탭 변경 시 실행하지 않고 선택 메뉴를 닫음.
- 관리자 전체/선택 작업 범위, 작업 메뉴 복귀 후 검색을 모델 입력으로 처리하지 않음.

## 실제 PTY

`TestInteractiveDashboardFixture`는 환경 변수로 켜는 테스트 전용 화면이다. 실제 Codex
엔진을 시작할 수 없는 RPC 기록 서버와 임시 파일만 사용한다. tmux에서 실행했다.

14개 흐름을 통과했다: 넓은 화면, 클릭으로 설정 열기/저장, 계정 역할·한도, 기기 로그인,
취소 후 코드 제거, 전체 기록, SGR 휠, F9 모든 동작, 새 작업 폼, 긴 폼 끝의 버튼,
좁은 입력창, 좁은 명령 목록, 기본 복사 모드.

해당 테스트의 기록은 설정 저장 1회·가짜 로그인 시작 1회·취소 1회·모델 호출 0회다.
테스트용 `codexm-tui-ux-test-20261022`, `codexm-tui-native-test-20261022`는 종료 후 정리했다.
이름이 같은 운영 세션이나 서비스는 제어하지 않았다.

이 Mac의 private 결과 위치:
`~/.local/state/codexm/validation/tui-management-parity-20261022/`.
캡처는 테스트 데이터만 포함한다. 로그인 URL/코드는 제품 로그·영속 UI 기록에 저장하지 않는다.

## 적용 범위

로컬 실행 파일을 `d5acbf1`의 source build로 설치했다. 기존 웹 번들의 digest
`a4791ddd61e0fa94379d4f17012a4f2129f1857a6d17077131f33ffd99e40447`를 보존하고
`codexm web verify`를 통과했다. 관리 설정 파일은 바이트 단위로 동일하다. 기존 10개
작업의 작업·대화·계정·실행 ID, 목표 예산 및 누적 사용량을 비교해 보존을 확인했다.

확인 중 native 인증 내용의 체크섬은 달라졌다. `auth.json`의 account-backup 연결은 같았고
`last_refresh`가 갱신됐다. 파일을 쓴 프로세스까지 특정하지는 않았다. 설치 경로는
버전 확인·빌드·웹 번들 복사와 config의 구형 필드 마이그레이션뿐이며, 인증을 쓰는
호출이 없는 것을 확인했다. 갱신된 인증을 이전 내용으로 되돌리지 않았다.

실행 중인 관리 서비스·기존 worker는 재시작하지 않았다. 배포 버전 번호는 0.6.2를
유지하고 immutable source hash로 구분했다. GitHub release/tag/npm/tap 배포는 하지 않았다.
운영 환경의 계정 변경이나 목표 실행은 사용자가 새 UI에서 명시적으로 요청할 때 수행된다.
